Four Simulators

Each simulator targets a different regime of quantum computation.

1. State-Vector Simulator

Full amplitude tracking for general quantum circuits. Memory scales as 16 * 2^n bytes.

from phase1_basic.simulators import StateVectorSimulator sim = StateVectorSimulator(n_qubits=20) sim.h(0) for i in range(19): sim.cnot(i, i+1) # 20-qubit GHZ state bench = sim.benchmark() # 20 qubits: 1,048,576 amplitudes, 16.00 MB

2. Clifford / Stabilizer Simulator

Gottesman-Knill theorem: Clifford circuits are classically simulable in polynomial time.

from phase1_basic.simulators import CliffordSimulator sim = CliffordSimulator(n_qubits=1000) sim.h(0) for i in range(999): sim.cnot(i, i+1) bench = sim.benchmark() # 1000 qubits: 314 KB memory, ~0.5 seconds # Equivalent state-vector: 1800 billion TB (impossible)

3. MPS (Matrix Product State) Simulator

Tensor network with controlled entanglement via SVD truncation.

from phase1_basic.simulators import MPSSimulator sim = MPSSimulator(n_qubits=50, max_bond_dim=32) sim.h(0) for i in range(49): sim.cnot(i, i+1) bench = sim.benchmark() # 50 qubits: max bond=2, ~2 KB memory # State-vector equivalent: 9 PB

4. Density Matrix Simulator

Tracks mixed states for realistic noise modeling.

from phase2_noise.noise_and_ec import NoiseChannels rho = np.zeros((2, 2), dtype=complex) rho[1, 1] = 1.0 # |1><1| # Apply amplitude damping (T1 relaxation) rho_damp = NoiseChannels.amplitude_damping(rho, gamma=0.3, n_qubits=1, target=0) # P(|0>) = 0.3000, P(|1>) = 0.7000

Quick Start

Run the complete simulation suite in minutes.

Installation

# Clone the repository git clone https://github.com/tonythetiger168/quantum-rd-plan.git cd quantum-rd-plan # No dependencies needed for core simulators (pure NumPy) # Optional: install quantum frameworks for cross-validation pip install qiskit cirq pennylane stim qutip quimb

Run All Milestones

# Run all three phases python -m qpu_sim_suite # Run specific phase python -m qpu_sim_suite --phase 1 # Basic simulators python -m qpu_sim_suite --phase 2 # Noise & EC python -m qpu_sim_suite --phase 3 # Algorithms

Example: Bell State

from phase1_basic.simulators import StateVectorSimulator sim = StateVectorSimulator(n_qubits=2) sim.h(0) sim.cnot(0, 1) sim.print_state() # |00>: 0.707107 # |11>: 0.707107 counts = sim.measure_all(shots=1024) # {'00': ~512, '11': ~512}

Example: VQE for H2

from phase3_scale.algorithms import VQE vqe = VQE(n_qubits=2, n_layers=2) ham = VQE.hydrogen_molecule_hamiltonian() result = vqe.optimize(hamiltonian=ham, max_iter=100) print(f"Ground state: {result['best_energy']:.6f} Ha") # Ground state: -1.137 Ha

Example: 1000-Qubit Clifford

from phase1_basic.simulators import CliffordSimulator sim = CliffordSimulator(n_qubits=1000) sim.h(0) for i in range(999): sim.cnot(i, i+1) # Completes in < 1 second # Memory: ~4 MB
